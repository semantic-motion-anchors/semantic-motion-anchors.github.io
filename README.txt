Semantic Motion Anchors: Bridging Motion and Meaning in Co-Speech Gestures
NeurIPS 2026

index.html is the paper homepage. dataset.html is the SEMANTIX dataset overview.
The site is static HTML, CSS, JavaScript and MP4. Publish the root directory using GitHub Pages.

The downstream application section pairs RAG-Gesture and Semantic Motion Anchors videos for 13 examples.
Each author-provided comparison shows its retrieved motion at left and generated motion at right.
The original comparison MP4s are unchanged. JPEG posters are frames from those videos.
The album presents five published SEMANTIX records. The three TED videos use official YouTube uploads. The two BEAT2 videos use renders hosted by the authors on Hugging Face.
